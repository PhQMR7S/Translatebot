# QMR Translate — ترجمة ملفات PDF داخل Telegram
يختار المستخدم ترجمة سطرية (إنجليزية ثم عربية) أو عربية كاملة. يعالج البوت PDF النصي ويرسل ملف PDF في المحادثة. مجاني ضمن حصص Gemini والاستضافة، دون نجوم أو شراء.

الحدود المعلنة: 20 MB، 120 صفحة، 150 ألف حرف. الصور وPDF المصور وWord غير مدعومة؛ تُرفض الملفات التي تحتوي صورًا بدل إسقاط نصوصها بصمت. العربية الكاملة تملأ مواضع النص الأصلية وتعاد صياغة تنسيق الصفحات تلقائيًا إذا لم يتسع النص. السطرية تزيد الصفحات ولا تحافظ على توزيع الصفحة الأصلي.

يُرسل النص إلى Gemini المجاني؛ قد يستخدمه المزود لتحسين منتجاته. يجب إزالة بيانات المرضى التعريفية. يفحص البرنامج أعداد المقاطع وترتيبها والأرقام وبعض الرموز؛ لا يدّعي تدقيق المعنى الطبي أو تصحيح أخطاء المصدر.

متغيرات البيئة: BOT_TOKEN وGEMINI_API_KEY وWEBHOOK_SECRET (32 حرفًا عشوائيًا أو أكثر). Render يوفر PORT وRENDER_EXTERNAL_URL. build: pip install -r requirements.txt. start: python bot.py. /health يعرض النسخة 2.0. اختبارات: python -m unittest discover -s tests -v.

المعالجة في الذاكرة: ملف واحد لكل مستخدم، ومهمة واحدة نشطة على الخدمة مع انتظار محدود. /status و/cancel متاحان. اختيار الملف ينتهي بعد 30 دقيقة أو إعادة تشغيل الخدمة. عند إعادة التشغيل تضيع الطلبات التي لم تكتمل ويجب إعادة إرسالها؛ لا تخزين دائم. الاستضافة المجانية تنام عند الخمول ولها ساعات مشتركة على مستوى مساحة Render. منع تكرار تحديثات Telegram محدود بعمر العملية؛ فشل الشبكة أثناء إرسال النتيجة قد يؤدي لعدم وضوح التسليم. لا ضمان لصفر أخطاء أو مطابقة تنسيق جميع ملفات PDF.

لا مفاتيح في المستودع أو سجلات المحتوى. الخط العربي DejaVu Sans مُضمّن مع ترخيصه، ومختزل للمحارف العربية واللاتينية المستخدمة.
