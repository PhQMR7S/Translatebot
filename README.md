# مِداد الطبي — نسخة مجانية إرشادية
تفتح للمستخدم موقع Online Doc Translator وتشرح رفع الملف وترجمته يدويًا. لا تترجم الملفات أو تراجعها تلقائيًا. لا مدفوعات أو باقات أو API ترجمة.
التشغيل عبر Telegram webhook وaiohttp. اضبط BOT_TOKEN وWEBHOOK_SECRET (32 حرفًا عشوائيًا أو أكثر) في أسرار Render. RENDER_EXTERNAL_URL وPORT يقدمهما Render. build: pip install -r requirements.txt. start: python bot.py. health: /health.
الخطة المجانية قد تتوقف عند الخمول ويتأخر أول رد عند العودة. لا حفظ لمحتوى الملفات ولا قاعدة بيانات. تكرار تسليم Telegram بعد فشل الشبكة قد ينتج ردًا مكررًا؛ لا أرصدة أو عمليات مالية تتأثر. كل النصوص توضح أن الترجمة تتم على الموقع يدويًا.
